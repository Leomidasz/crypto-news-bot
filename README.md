# บอทสรุปข่าวคริปโต (X + Discord → แอปมือถือ + Telegram)

ดึงโพสต์จากบัญชี X ที่เลือก + ข้อความจากช่อง Discord → ให้ Claude สรุปเป็นภาษาไทย ใช้ได้ 2 แบบ (เลือกแบบเดียวหรือทั้งคู่ก็ได้)

| | A. สรุปอัตโนมัติทุกเช้า + แอปมือถือ | B. บอท Telegram สั่ง `/news` |
|---|---|---|
| ทำงานยังไง | GitHub รันให้ทุกเช้า ~06:40 → อัปเดตแอป + แจ้งเตือน Telegram | พิมพ์ `/news` เมื่อไหร่ก็ได้ ได้สรุปทันที |
| ต้องเปิดคอมไหม | **ไม่ต้อง** | ต้องเปิดคอมที่รัน `bot.py` ไว้ |
| อ่านที่ไหน | แอปในหน้าจอมือถือ (ย้อนหลังได้) | ในแชท Telegram |
| ตั้งค่า | ขั้นตอน 3–6 แล้วไป **ส่วน A** ท้ายคู่มือ | ขั้นตอน 1–9 |

> ขั้นตอนที่ 3–6 (สมัครกุญแจ API) ใช้ร่วมกันทั้งสองแบบ ถ้าจะใช้แค่แบบ A ข้ามขั้นตอน 1–2 และ 7–9 ได้เลย

คำสั่งของแบบ B:
```
/news          สรุป 12 ชม.ล่าสุด (X + Discord)
/news 24       สรุป 24 ชม.ล่าสุด
/news_x 6      เฉพาะ X, 6 ชม.
/news_dc       เฉพาะ Discord
/sources       ดูว่าติดตามบัญชี/ช่องไหนอยู่
/start         ดู chat id ของตัวเอง
```

## ขั้นตอนที่ 4 — X (Twitter) API

1. ไปที่ https://console.x.com → ล็อกอินด้วยบัญชี X
2. สร้าง Project + App ใหม่
3. เติมเครดิต (ตอนนี้ X คิดเงินแบบ pay-per-use ไม่มีแพ็กเกจฟรีแล้ว) — เริ่มที่ $5–10 ก็พอทดสอบ

**ค่าใช้จ่ายโดยประมาณ:** ประมาณ $0.005 ต่อโพสต์ที่ดึงมา
- บอทจำโพสต์ที่ดึงแล้วไว้ในไฟล์ `newsbot.db` → สั่ง `/news` ซ้ำไม่เสียเงินกับโพสต์เดิม

- อยากประหยัด: ลดจำนวนบัญชี หรือลด `X_MAX_POSTS_PER_ACCOUNT`
- ครั้งแรกที่เจอชื่อบัญชีใหม่ จะเสียค่าค้นหา user อีก ~$0.01 ต่อบัญชี (ครั้งเดียว)

## ขั้นตอนที่ 5 — Discord Bot

### 5.1 สร้างบอท
1. ไปที่ https://discord.com/developers/applications → **New Application** → ตั้งชื่อ
2. เมนูซ้าย **Bot** → กด **Reset Token** → คัดลอก → ใส่ `DISCORD_BOT_TOKEN`
3. หน้าเดียวกัน เลื่อนลงไป **Privileged Gateway Intents** → เปิด **MESSAGE CONTENT INTENT** → Save
   (ถ้าไม่เปิด บอทจะเห็นข้อความแต่เนื้อหาว่างเปล่า)

### 5.2 เชิญบอทเข้าเซิร์ฟเวอร์
1. เมนูซ้าย **OAuth2** → **URL Generator**
2. Scopes: ติ๊ก `bot`
3. Bot Permissions: ติ๊ก `View Channels` และ `Read Message History`
4. คัดลอกลิงก์ด้านล่าง → เปิดในเบราว์เซอร์ → เลือกเซิร์ฟเวอร์ของคุณ → Authorize

### 5.3 หา Channel ID
1. ใน Discord: User Settings → Advanced → เปิด **Developer Mode**
2. คลิกขวาที่ช่องที่อยากดึง → **Copy Channel ID**
3. ใส่ใน `DISCORD_CHANNEL_IDS` (หลายช่องคั่นด้วย `,`)

> ⚠️ **ถ้าข่าวอยู่ในเซิร์ฟเวอร์ของคนอื่น** (ที่คุณเชิญบอทเข้าไม่ได้): ให้กด **Follow** ที่ช่อง Announcement ของเขา แล้วเลือกให้ส่งมาที่ช่องในเซิร์ฟเวอร์ของคุณเอง จากนั้นให้บอทอ่านช่องของคุณแทน
> **ห้ามใช้ user token ของบัญชีตัวเองดึงข้อมูล (self-bot)** — ผิดกฎ Discord และเสี่ยงโดนแบนบัญชี

## ใช้หลายเครื่อง (คอมบ้าน + คอมที่ทำงาน)

ใช้ได้ครับ แต่มี **กฎข้อเดียว: เปิดบอทได้ทีละเครื่องเท่านั้น**
Telegram ยอมให้โปรแกรมเดียวรับคำสั่งของบอทตัวหนึ่งในเวลาเดียวกัน ถ้าเปิด 2 เครื่องพร้อมกัน หน้าจอจะขึ้นเตือน
`⚠️ บอทตัวนี้กำลังเปิดอยู่ที่เครื่องอื่น!` → ให้ปิดเครื่องหนึ่งก่อน (กด `Ctrl + C`)

**วันปกติ:**
- ถึงที่ทำงาน → ปิดบอทที่บ้าน (ถ้าเปิดทิ้งไว้) → เปิด `start_bot.bat` ที่คอมทำงาน
- กลับบ้าน → ปิดที่ทำงาน → เปิดที่บ้าน
- มือถือใช้ได้ตลอดตราบที่มีเครื่องใดเครื่องหนึ่งเปิดบอทอยู่
- คำสั่ง `/news` ที่พิมพ์ตอนไม่มีเครื่องไหนเปิดอยู่ จะถูกทิ้งไป (กันเปิดเครื่องมาแล้วบอทรันคำสั่งเก่ารัวๆ จนเสียเงิน) → เปิดบอทแล้วพิมพ์ใหม่

### ติดตั้งบนเครื่องที่ 2
1. คัดลอกโฟลเดอร์บอทไปเครื่องใหม่ (ผ่าน GitHub, USB หรือ Google Drive) — **ไม่ต้องเอาโฟลเดอร์ `.venv` ไป** เพราะต้องสร้างใหม่ทุกเครื่อง
2. คัดลอกไฟล์ `.env` ไปด้วย (ทาง USB หรือส่งหาตัวเองแบบส่วนตัว) — **ห้ามอัปขึ้น GitHub** เพราะมีรหัสทั้งหมดอยู่ในนั้น
3. ทำขั้นตอนที่ 1–2 ของคู่มือบนเครื่องนั้น (ติดตั้ง Python, สร้าง `.venv`, `pip install`)
4. ดับเบิลคลิก `start_bot.bat` → ใช้ได้เลย ไม่ต้องตั้ง chat id ใหม่

> ไฟล์ `newsbot.db` (ความจำโพสต์ที่ดึงแล้ว) แยกกันแต่ละเครื่อง ไม่ต้องคัดลอก — ผลคือตอนสลับเครื่องครั้งแรก บอทจะดึงโพสต์ช่วงนั้นซ้ำ เสียเพิ่มแค่ไม่กี่บาท

### ⚠️ ข้อควรระวังเรื่องคอมที่ทำงาน
- **ติดตั้ง Python ไม่ได้เพราะไม่มีสิทธิ์ admin:** ตอนติดตั้ง Python ให้เลือก **"Install for current user"** (ไม่ต้องใช้สิทธิ์ admin)
- **เน็ตบริษัทบล็อก Telegram/Discord:** บอทจะค้างหรือขึ้น error `NetworkError` / `ConnectTimeout` → เครื่องนั้นใช้ไม่ได้ ต้องใช้เครื่องบ้านหรือ VPS แทน
- **นโยบายบริษัท:** บางที่ห้ามติดตั้งโปรแกรมหรือรันสคริปต์ส่วนตัวบนเครื่องบริษัท — เช็คกับฝ่าย IT ก่อนจะปลอดภัยกว่า

## ส่วน A — สรุปอัตโนมัติทุกเช้า + แอปมือถือ (ผ่าน GitHub)

GitHub จะเป็นทั้ง "เครื่องรันบอท" (GitHub Actions — รันทุกเช้าให้ฟรี) และ "เว็บโฮสต์" ของแอป (GitHub Pages) → ไม่ต้องเปิดคอมทิ้งไว้

```
ทุกเช้า 06:40 ─▶ GitHub Actions: ดึง X + Discord → Claude สรุป → บันทึกไฟล์สรุป
                        │
                        ├─▶ แอป "ข่าวเช้า" ในมือถืออัปเดต (ดูย้อนหลังได้ทุกวัน)
                        └─▶ Telegram เด้งแจ้งเตือน พร้อมลิงก์เปิดแอป
```

### 🔓 repo แบบ Public (ฟรี)
คู่มือนี้ใช้ repo แบบ **Public** ไม่ต้องจ่ายค่า GitHub
- **คนอื่นเห็นได้:** โค้ด, ไฟล์สรุปข่าวรายวันใน `docs/data/`, ชื่อบัญชี X และชื่อช่อง Discord ที่อยู่ในสรุป
- **ปลอดภัย:** กุญแจ API และค่าใน Secrets/Variables คนนอกมองไม่เห็น, คนนอกสั่งรันบอทไม่ได้, บันทึกการรัน (log) GitHub ซ่อนกุญแจเป็น `***` ให้อัตโนมัติ
- หน้าแอปตั้งค่าห้าม Google เก็บไปแสดงในผลค้นหาไว้แล้ว
- **ควรเปิด 2FA** ให้บัญชี GitHub: https://github.com/settings/security → Two-factor authentication
- อยากให้เป็นส่วนตัวทีหลัง: เปลี่ยนเป็น Private + สมัคร GitHub Pro (~$4/เดือน) หรือฝากเว็บที่ Cloudflare Pages (ฟรี)

### A1. สร้าง repo บน GitHub
1. ล็อกอิน https://github.com → มุมขวาบนกด **+** → **New repository**
2. Repository name: `crypto-news-bot`
3. เลือก **Public** → กด **Create repository**
   (ถ้าสร้างเป็น Private ไปแล้ว: Settings → เลื่อนลงล่างสุด **Danger Zone** → **Change visibility** → **Change to public**)

### A2. อัปโหลดไฟล์
1. แตกไฟล์ zip ในคอม
2. ในหน้า repo ใหม่ กดลิงก์ **uploading an existing file**
3. เปิดโฟลเดอร์ที่แตกไว้ → **เลือกทุกอย่างข้างใน** (รวมโฟลเดอร์ `.github` และ `docs`) → ลากไปวางในหน้าเว็บ
   - **ห้ามอัปโหลด** `.env`, `.venv`, `newsbot.db` (ถ้ามี)
4. เลื่อนลงกด **Commit changes**
5. เช็ค: ในหน้า repo ต้องเห็นโฟลเดอร์ `.github` และ `docs`
   - ถ้าไม่เห็น `.github`: กด **Add file → Create new file** → ช่องชื่อพิมพ์ `.github/workflows/daily-digest.yml` → เปิดไฟล์นั้นในคอมด้วย Notepad คัดลอกเนื้อหามาวาง → Commit changes

### A3. ใส่กุญแจลับ (Secrets)
ในหน้า repo → **Settings** → เมนูซ้าย **Secrets and variables** → **Actions** → แท็บ **Secrets** → กด **New repository secret** ทีละตัว:

| Name | Value |
|---|---|
| `X_BEARER_TOKEN` | จากขั้นตอนที่ 4 |
| `DISCORD_BOT_TOKEN` | จากขั้นตอนที่ 5 |
| `ANTHROPIC_API_KEY` | จากขั้นตอนที่ 6 |
| `TELEGRAM_BOT_TOKEN` | จากขั้นตอนที่ 3 (ไม่ใส่ก็ได้ถ้าไม่อยากได้แจ้งเตือน) |
| `TELEGRAM_ALLOWED_CHAT_IDS` | chat id ของคุณ (ดูวิธีหาด้านล่าง) |

**หา chat id:** ใน Telegram ทักบอท **@userinfobot** → มันจะตอบเลข `Id` มา นั่นคือ chat id
แล้ว **ต้องเข้าไปกด Start ที่บอทของคุณเองหนึ่งครั้ง** ไม่งั้นบอทส่งข้อความหาคุณไม่ได้

### A4. เปิดเว็บแอป (GitHub Pages)
1. **Settings** → เมนูซ้าย **Pages**
2. Source: **Deploy from a branch** → Branch: **main** → โฟลเดอร์: **/docs** → **Save**
3. รอ 1–2 นาที รีเฟรชหน้า จะเห็นลิงก์แบบ `https://ชื่อคุณ.github.io/crypto-news-bot/` → คัดลอกไว้

### A5. ตั้งค่าทั่วไป (Variables)
**Settings → Secrets and variables → Actions** → แท็บ **Variables** → **New repository variable**:

| Name | ตัวอย่าง Value |
|---|---|
| `X_ACCOUNTS` | `WatcherGuru,tier10k,lookonchain` |
| `DISCORD_CHANNEL_IDS` | `123456789012345678,234567890123456789` |
| `APP_URL` | ลิงก์จากขั้นตอน A4 |

(ไม่บังคับ: `CLAUDE_MODEL`, `X_MAX_POSTS_PER_ACCOUNT`)
อยากเพิ่ม/ลบบัญชี X ทีหลัง → แก้ `X_ACCOUNTS` ตรงนี้ ไม่ต้องแตะโค้ด

### A6. สั่งรันครั้งแรก (ไม่ต้องรอถึงพรุ่งนี้)
1. แท็บ **Actions** ด้านบน (ถ้ามีปุ่มเขียวให้เปิดใช้ workflows ให้กดก่อน)
2. เมนูซ้าย **Daily crypto digest** → ขวามือกด **Run workflow** → **Run workflow**
3. รอ ~1–2 นาที จนขึ้นเครื่องหมาย ✅ สีเขียว
   - ขึ้น ❌ สีแดง: กดเข้าไปดู → กดขั้น **Fetch + summarize + save** จะเห็นข้อความ error (ดูตารางแก้ปัญหา)
4. Telegram จะเด้งแจ้งเตือน → รออีก ~1 นาทีให้ Pages อัปเดต แล้วเปิดลิงก์แอป

หลังจากนี้ระบบรันเองทุกเช้า ~06:40 (GitHub อาจช้ากว่านี้ 5–30 นาทีบางวัน)
**กดรันเองจากมือถือได้:** ติดตั้งแอป GitHub → เข้า repo → Actions → Daily crypto digest → Run workflow

### A7. ติดตั้งแอปลงหน้าจอมือถือ
เปิดลิงก์แอป (`APP_URL`) แล้ว:
- **Android (Chrome):** กดเมนู ⋮ มุมขวาบน → **เพิ่มลงในหน้าจอหลัก / Install app**
- **iPhone (ต้องใช้ Safari):** กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) → **เพิ่มไปยังหน้าจอโฮม**

จะได้ไอคอนพระอาทิตย์ "ข่าวเช้า" บนหน้าจอ เปิดแล้วเต็มจอเหมือนแอปทั่วไป
- สีแถบด้านบนบอกบรรยากาศตลาด: 🟢 เขียว = บวก · 🔴 แดง = ลบ · 🟡 เหลือง = ผสม · ⚪ เทา = ทรงตัว
- ปุ่ม **ย้อนหลัง** = ดูสรุปวันก่อนๆ · แถบหมวด = กรองเฉพาะเรื่องที่สนใจ
- ข่าวที่ติดป้าย **ยังไม่ยืนยัน** = ข่าวลือ อย่าเพิ่งเชื่อ

### ค่าใช้จ่ายแบบ A
- GitHub: **ฟรี** (repo Public ใช้ Actions และ Pages ได้ฟรี บอทนี้ใช้วันละ ~1–2 นาที)
- X API + Claude: จ่ายตามจริงเหมือนเดิม แต่รันแค่วันละครั้ง ประหยัดกว่าสั่ง `/news` บ่อยๆ

### ข้อควรรู้
- GitHub อาจปิด workflow ที่ตั้งเวลาไว้อัตโนมัติ ถ้า repo ไม่มีความเคลื่อนไหว 60 วัน — ถ้าได้อีเมลแจ้ง ให้เข้าแท็บ Actions แล้วกด **Enable workflow**
- ใช้แบบ A คู่กับแบบ B ได้ (token Telegram เดียวกันได้ เพราะแบบ A แค่ "ส่ง" ข้อความ ไม่ได้ "รับ" คำสั่ง จึงไม่ชนกัน)
- ทดสอบบนคอมก่อนได้: `python publish.py` → จะสร้างไฟล์ใน `docs/data/` (ไม่ต้องอัปโหลดไฟล์ทดสอบนี้ขึ้น GitHub)

## แก้ปัญหา

| ข้อความที่เจอ | สาเหตุ / วิธีแก้ |
|---|---|
| `X API error 401` | Bearer Token ผิด → Generate ใหม่ |
| `เครดิต X API หมด` (402) | เติมเครดิตใน console.x.com |
| `X: ไม่พบบัญชี @xxx` | สะกดชื่อผิด หรือบัญชีถูกระงับ |
| `Discord ช่อง ... เข้าไม่ได้ (403)` | บอทไม่ได้อยู่ในเซิร์ฟเวอร์ หรือไม่มีสิทธิ์ View Channel/Read Message History ในช่องนั้น |
| `Discord ช่อง ... เข้าไม่ได้ (404)` | Channel ID ผิด |
| `เนื้อหาว่างทั้งหมด` | ยังไม่ได้เปิด MESSAGE CONTENT INTENT (ขั้นตอน 5.1 ข้อ 3) |
| `AuthenticationError` | ANTHROPIC_API_KEY ผิด |
| `⛔ chat นี้ยังไม่ได้รับอนุญาต` | ยังไม่ได้ใส่ chat id ใน `.env` หรือยังไม่ได้รีสตาร์ทบอท |
| `Conflict` / `บอทตัวนี้กำลังเปิดอยู่ที่เครื่องอื่น` | มีอีกเครื่องเปิดบอทอยู่ (เช่น ลืมปิดที่บ้าน) หรือ Hongthong ใช้ token เดียวกัน → ปิดอีกเครื่อง หรือใช้ token แยก |
| `NetworkError` / `ConnectTimeout` | เน็ตเครื่องนั้นบล็อก Telegram/Discord/X (พบบ่อยในเน็ตบริษัท) |
| แอปขึ้น "ยังไม่มีสรุป" | ยังไม่เคยรัน workflow สำเร็จ → ทำขั้นตอน A6 |
| Actions ❌ ที่ขั้น Commit new digest | Settings → Actions → General → Workflow permissions → เลือก **Read and write permissions** → Save แล้วรันใหม่ |
| ลิงก์แอปขึ้น 404 | ยังไม่ได้ตั้ง Pages (A4) หรือเลือกโฟลเดอร์ผิด (ต้องเป็น `/docs`) หรือรอไม่ถึง 2 นาที |
| หน้า Pages ไม่มีตัวเลือกให้เปิด / บอกให้อัปเกรด | repo ยังเป็น Private → เปลี่ยนเป็น Public (ดูขั้นตอน A1) |
| ไม่มีแจ้งเตือน Telegram ตอนเช้า | ยังไม่ได้กด Start ที่บอทตัวเอง หรือ chat id / token ใน Secrets ผิด |

## รวมเข้ากับ Hongthong Bot (ทีหลัง)

**ถ้า Hongthong ใช้ไลบรารี `python-telegram-bot`:**
1. คัดลอกไฟล์ `config.py, storage.py, x_source.py, discord_source.py, summarizer.py, digest.py, bot.py` ไปไว้ในโปรเจกต์ Hongthong (หรือโฟลเดอร์ย่อย)
2. เพิ่มค่าจาก `.env` ของบอทนี้เข้าไปใน `.env` ของ Hongthong
3. ในไฟล์ที่ Hongthong สร้าง `Application` ให้เพิ่ม 2 บรรทัด:
   ```python
   from bot import register_handlers
   register_handlers(app)   # app คือ Application ของ Hongthong
   ```
   → Hongthong จะมีคำสั่ง `/news`, `/news_x`, `/news_dc`, `/sources` เพิ่มทันที

**ถ้าใช้ไลบรารีอื่น (เช่น aiogram, telebot):** เรียกฟังก์ชันหลักตรงๆ แทน
```python
from digest import build_digest
text = await build_digest(12)   # ได้ข้อความสรุป แล้วส่งด้วยวิธีของบอทนั้น
```
(ข้อความอาจยาวเกิน 4,096 ตัวอักษร ใช้ `split_message()` จาก `bot.py` ช่วยตัดได้)
